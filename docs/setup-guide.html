Moschee einrichten

Diese Checkliste führt Sie durch die Erstkonfiguration — von der Registrierung bis zum ersten Unterrichtstag.

Registrierung abschließen

Wählen Sie einen Plan, legen Sie Ihre Moschee an und erstellen Sie das Admin-Konto. Nach der Registrierung sind Sie automatisch angemeldet.

Moschee-Profil vervollständigen

Unter „Einstellungen → Allgemein“ laden Sie ein Logo hoch, hinterlegen die Adresse und wählen Sprache sowie Farbschema.

  • Logo hochladen (empfohlen: quadratisch, mind. 256×256 px)
  • Farbe & Logo werden in E-Mails und auf der Anmeldeseite angezeigt
Schuljahr definieren

Unter „Einstellungen → Schuljahr“ legen Sie den aktuellen Zeitraum fest (z. B. 1. September – 30. Juni). Alle Anwesenheiten und Hausaufgaben werden diesem Zeitraum zugeordnet.

Erste Gruppen anlegen

Gruppen sind das Herzstück der Organisation. Legen Sie unter „Gruppen → Neue Gruppe“ mindestens eine Lerngruppe mit Name, Altersstufe und Wochentagen an.

  • Beispiel: „Kinder A (Mo+Mi)“ oder „Jugend (Fr)“
  • Lehrer können nachträglich zugewiesen werden
Lehrkräfte erstellen

Unter „Lehrer → Lehrer hinzufügen“ erzeugen Sie Konten für Ihre Lehrkräfte. Das System versendet automatisch Willkommens-E-Mails mit temporären Passwörtern.

  • Lehrer können mehreren Gruppen zugeordnet werden
  • Bei der ersten Anmeldung müssen sie ihr Passwort ändern
Lektionen & Themen aufbauen

Unter „Lektionen“ legen Sie den Unterrichtsstoff an. Sie können Themen und Unterthemen manuell erstellen oder aus vordefinierten Vorlagen importieren.

  • Sequenzieller Religionsunterricht, Quran, Gebetslehre etc.
  • Lektionen lassen sich später Hausaufgaben zuordnen
Schüler & Eltern eintragen

Schüler unter „Schüler → Hinzufügen“ anlegen und mit Eltern verknüpfen. Eltern erhalten automatisch Zugriff auf das Elternportal.

  • Import per CSV möglich (wenn verfügbar)
  • Mindestens ein Elternteil pro Schüler empfohlen
Kalender & erste Termine

Unter „Kalender“ tragen Sie wichtige Termine ein: Schuljahresbeginn, Feiertage, Elternabende. Alle Benutzer sehen diese Termine in ihrem Portal.

  • Termine können mit Teilnehmern (Gruppen, Lehrer, Eltern) verknüpft werden
  • Automatische E-Mail-Benachrichtigung bei neuen Terminen

Sie sind startklar!

Wenn alle 8 Schritte abgehakt sind, können Sie mit dem regulären Betrieb beginnen: Anwesenheiten erfassen, Hausaufgaben verteilen und den Fortschritt verfolgen.

Nächste Schritte

  • Demo testen: Nutzen Sie den Demo-Modus, um alle Funktionen ohne echte Daten auszuprobieren.
  • Prüfungen einrichten: Falls Sie das Prüfungssystem nutzen möchten, definieren Sie unter „Einstellungen → Prüfungen“ die Kriterien.
  • Plugins erkunden: Unter „Einstellungen → Plugins“ können Sie zusätzliche Module aktivieren.
  • 2FA aktivieren: Empfohlen für alle Admin-Kontos: Zwei-Faktor-Authentifizierung im Konto-Menü einrichten.
